## Notes on Output Generation

- `generated-testcases.xlsx` is written by this agent as **CSV-shaped text** matching the column spec in `output-format.md` (Test Case ID, Test Case Name, Requirement ID, Scenario ID, Priority, Severity, Status, Test Step #, Test Step Description, Expected Result, Actual Result, Step Status, Log Attachment, Attachments, Tags) with one row per test step and test-case metadata repeated on every step row. It is **not yet a native binary `.xlsx` workbook**.
- The orchestrator is responsible for running `node scripts/csv-to-xlsx.js reports/SCRUM-101/generated-testcases.xlsx` afterward to convert it into a properly formatted native workbook (bold header, frozen first row, auto-fit columns) in place.
- For the 7 confirmed-defect test cases (TC-005, TC-011, TC-012, TC-013, TC-022, TC-024, TC-026), the CSV's `Actual Result` and `Step Status` columns are pre-filled with the observed live-application behavior and a "Fail — Confirmed Defect" status (rather than left blank), because the Structured Test Plan already documents these as confirmed findings from live exploration on 2026-09-16. All other test cases use the standard defaults (`Status` = Draft, `Actual Result` = blank, `Step Status` = blank) pending formal manual execution.
